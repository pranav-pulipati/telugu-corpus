# Changelog — catalogue audit of 2026-11-09

Every change made to the 204 original records, generated by `scripts/audit_outputs.py` by comparing `audit/original_snapshot/MASTER_CATALOGUE.csv` with `audit/CORRECTED_CATALOGUE.csv`. The reason for each change is in the record's `audit_notes` (shown first). Fields added by the audit (quality_rating, content_role, dedup_role, canonical_record, count_in_totals, telugu_content_check, audit_status, audit_notes, rejection_reason) are set on every record and are not repeated below.

## Repository-level changes

- Original records preserved unchanged in `audit/original_snapshot/` (records YAML, master CSV/XLSX, verification log, HF inventory).
- Corrections are applied by `scripts/apply_audit.py` (reproducible: original snapshot + decisions → corrected records).
- Rejected records moved to `data/rejected/rejected_records.yaml` and the XLSX sheet 'Rejected (archive)'; excluded from MASTER_CATALOGUE.
- Schema: 10 audit fields added (`data/schema.yaml`).
- New checks: `scripts/hf_telugu_check.py`, `scripts/hf_telugu_recheck.py` (sampled-row Telugu detection), `scripts/validate.py` (automated quality checks).
- `scripts/link_check.py`: removed the fallback that disabled TLS certificate verification; invalid certificates are now reported as failures.
- HF inventory: added sampled-content verdict and Retained/Rejected/Unconfirmed decision per dataset.
